# SwiftCounterApp

A simple SwiftUI counter app for iOS.

## Features

- Displays the current count
- **Increment** button to increase the count by 1
- **Reset** button to set the count back to 0

## Requirements

- Xcode 15+
- iOS 17+
- Swift 5.9+

## Getting Started

1. Clone the repository
2. Open `SwiftCounterApp.xcodeproj` in Xcode
3. Select a simulator or device
4. Build and run (`Cmd+R`)

## Project Structure

```
SwiftCounterApp/
├── SwiftCounterAppApp.swift   # App entry point
├── ContentView.swift          # Counter UI and logic
└── Assets.xcassets/           # App icons and colors
```
